# SRAGROUP corporate website

## Build
- Create a shared sticky header, mobile navigation, footer, page headers, calls to action, and reusable content components.
- Build six Italian routes: Home, Chi Siamo, Costruzioni, Fotovoltaico, Progetti, and Contatti.
- Add local project data for six filterable case studies and a contact form with division-specific fields and client-side success state.
- Add cohesive local construction and solar imagery, plus the provided logo when available.

## Visual direction
- Industrial, restrained, premium styling with dark charcoal and off-white foundations.
- Amber appears only in construction content; green appears only in solar content.
- Space Grotesk headings, Inter body, strong grids, large photography, subtle motion, and responsive mobile layouts.

## Technical details
- Keep TanStack Router as the project router while implementing the requested React page structure.
- Use semantic Tailwind v4 tokens and reusable React components.
- Add unique Italian metadata for every route, then validate build health and key desktop/mobile interactions.
